SITE MAÉVA CHAUDERON — MODE D'EMPLOI

FICHIERS PRINCIPAUX
- index.html : contenu du site
- styles.css : design et responsive
- script.js : menu mobile et animations
- assets/logo-maeva.png : logo

À MODIFIER AVANT PUBLICATION
1. Rechercher "Adresse à compléter" dans index.html et indiquer l'adresse du cabinet.
2. Rechercher "XX €" et indiquer le tarif.
3. Rechercher "À compléter" pour ajouter durée, paiement, diplôme, école, numéro RPPS/ADELI et formations.
4. Ajouter une photo professionnelle dans assets puis remplacer le bloc portrait-placeholder.
5. Ajouter le lien Doctolib sur les boutons de prise de rendez-vous lorsqu'il sera disponible.
6. Compléter les mentions légales et la politique de confidentialité.

PUBLICATION GITHUB PAGES
